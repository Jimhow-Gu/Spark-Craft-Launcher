# PMGL - Python Minecraft Game Launcher

基于 **PySide6 + PyQt-Fluent-Widgets + minecraft-launcher-lib** 开发的现代化 Minecraft Java 版启动器。

## ✨ 功能特性

- 🎮 **版本管理**：浏览、下载、安装 Minecraft 正式版/快照版
- 🧩 **模组下载**：Modrinth / CurseForge 双数据源，支持分页页码、加载器/版本/分类筛选与一键下载
- 📦 **整合包导入**：支持 Modrinth `.mrpack` 与 CurseForge 整合包 `.zip`，自动安装对应加载器并启用版本隔离
- 🔧 **游戏修复**：游戏设置内一键校验版本 JSON、客户端 JAR、依赖库、资源文件与 natives，自动补全缺失/损坏文件
- 🎨 **OptiFine 支持**：自动区分独立安装版与需要 Forge 的版本；需要 Forge 时自动安装对应 Forge 并放入 mods
- 🖥️ **左侧导航**：下载中心采用左侧分类导航（版本 / 模组 / 整合包 / 数据包 / 资源包 / 光影包）
- 🖼️ **启动器背景**：读取 `Pictures` 文件夹图片，支持自动/平铺/居中/拉伸/九宫格对齐、不透明度、模糊与彩色叠加
- 🏷️ **自定义标题**：全局设置可修改启动器/游戏窗口标题，默认 `PMGL`
- 🔗 **前置模组提示**：模组版本页会自动显示必需前置（名称 + 图标），点击即可跳转下载
- 🎯 **高亮选择**：Mod 版本选择改为整行高亮选中，不再使用单选按钮
- 🔐 **登录方式**：离线模式、微软正版登录、LittleSkin / 自定义 Authlib Injector 第三方登录
- 🧑‍🎨 **离线皮肤**：默认随机史蒂夫/艾力克斯，支持正版玩家名皮肤与本地皮肤文件
- 🚀 **多实例启动**：可同时运行多个游戏实例；上一个启动成功后才能启动下一个，运行中的实例可单独结束
- 🧯 **崩溃诊断**：自动分析常见崩溃原因（Mod 冲突、缺少 Fabric API、Java 版本、内存、OpenGL 等），支持一键导出日志 ZIP
- ⚙️ **高级选项**：全局和版本独立设置均支持 JVM 参数、游戏参数、启动前命令、Java 列表、GC 模式（ZGC/G1GC）等
- 🧵 **下载线程数**：全局设置可调 1-100，默认 5；超过 10 会提示网络卡顿风险
- ⚙️ **灵活配置**：Java 路径自动检测、内存分配、下载镜像源切换
- 🛡️ **异常防护**：中文路径检测、Java 有效性校验、启动前完整检查、后台线程安全退出

## 📁 项目结构

```
mc_launcher/
├── main.py                  # 程序入口
├── config.py                # 配置管理（单例）
├── requirements.txt         # 依赖清单

│   ├── version.py           # 版本管理 + 安装线程
│   ├── auth.py              # 登录认证（离线/微软）
│   └── launch.py            # 启动命令构造 + 进程管理

    ├── main_window.py       # 主窗口（Fluent 导航）
    ├── widgets/

        ├── version_page.py  # 版本管理页
```

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行启动器

```bash
python main.py
```

### 3. 使用步骤

1. **配置 Java**：打开「设置」，点击「自动检测」或手动选择 `javaw.exe`
   - MC 1.20.5+ 需要 Java 21
   - MC 1.17 ~ 1.20.4 需要 Java 17
   - MC 1.16.5 及以下需要 Java 8

2. **下载版本**：进入「版本管理」→「下载新版本」，选择版本后点击安装
   - 国内用户建议在设置中切换为 **BMCLAPI 镜像**加速下载

3. **选择登录方式**：
   - **离线模式**：在「账号」页面输入玩家名即可，适合单机游玩
   - **微软登录**：点击「打开登录页面」，浏览器授权后将授权码粘贴回来

4. **启动游戏**：回到「启动」页面，选择版本，点击「启动游戏」

### CurseForge 数据源
下载中心默认使用 **Modrinth**，无需配置。若要使用 CurseForge 搜索：
1. 打开[https://console.curseforge.com/](https://console.curseforge.com/) 申请免费 API Key
2. 在「全局设置 → 模组下载源」中粘贴 Key
3. 在下载页右上角数据源切换到 CurseForge

本地 CurseForge 整合包导入不需要 API Key：会通过 CFWidget 公开元数据解析文件名，
并从 ForgeCDN 下载；解析失败时才建议配置 Key。

### 游戏修复
进入「游戏设置」→「游戏修复」，点击按钮即可自动校验并补全缺失文件；
修复优先使用 BMCLAPI 镜像，耗时取决于缺失文件数量。

### 整合包导入
在「整合包」下载页点击「导入本地整合包」，选择 `.mrpack` 或 CurseForge `.zip`；
导入后会自动创建独立版本并启用版本隔离。
导入时会从包内提取 `icon.png`、`pack.png`、`logo.png`（含 `overrides/loading/logo.png`）
作为版本图标，首页当前版本和已安装列表优先显示它；图标缺失或损坏时回退到 Forge /
Fabric / NeoForge / OptiFine 加载器图标。

### 账号与披风
- 左侧边栏标题下方的「账户」卡片显示当前 MC 头像、昵称和登录模式，点击直接进入账号设置。
- 「账号 → 切换账号」支持保存多个账号、删除账号，以及「添加新账号」。
  新账号使用微软设备码登录，登录过程中按钮会显示总进度，成功后自动关闭窗口并切到新账号。
- 微软设备码会弹出窗口显示并自动复制到剪贴板；点「确定 / 复制」打开登录网页。
- 第三方登录支持「记住账号和密码」（Windows 下用当前用户 DPAPI 加密）和密码显示/隐藏按钮。
- 登录方式面板会自动把当前游戏登录方式置顶并展开，其余方式折叠；离线昵称会自动记住。
- 只有微软正版登录会显示「皮肤 / 披风」「修改账号信息」「切换账号」按钮；
  第三方/离线模式只保留对应的退出登录按钮。
- 微软启动参数（令牌刷新、Java 检测）在后台准备，避免点击启动时窗口短暂无响应。
- 「账号 → 👕 → 修改披风」会从当前微软账号的 Minecraft 官方档案读取披风列表，
  选择后通过官方接口立即应用，不使用本地写死的披风清单。

### OptiFine
优先使用 BMCLAPI 的 `getOptifine` 接口与 Maven 镜像下载；BMCLAPI 下载失败时自动切换 OpenBMCLAPI，
仍缺少对应版本时再回退到 OptiFine 官方下载页解析。

### 下载性能
- 下载线程默认 64，最高 256。
- 全局下载速度限制最低 0.1 MB/s，最右侧为无限制（默认）。

### 下载镜像
全局设置 → 下载镜像 可分别设置「文件下载源」和「版本列表源」：
- 优先使用官方源，加载缓慢时自动换用 BMCLAPI / OpenBMCLAPI 镜像（默认）
- 优先使用 BMCLAPI 镜像源
- 仅使用官方源

客户端 JAR、资源对象和 Maven 依赖均支持 OpenBMCLAPI 兜底，
可解决 BMCLAPI 将客户端文件重定向到官方源后无法下载的问题。

### 游戏文件夹
「已安装版本」右上角可切换已保存的游戏文件夹，切换后自动加载其中的全部 MC 版本；
「＋」添加文件夹，「✕」只从列表移除保存项，不会删除磁盘上的文件。

### 下载版本
- 下载列表只显示版本名，不再附加 `(release/snapshot)` 类型后缀，默认筛选正式版。
- 正式版和快照版使用 `ui/imgs/Release.png` / `ui/imgs/Snapshoot.png` 图标区分。
- 「全部」筛选会先列出正式版，再列出快照和远古版本，不再受 300 条上限影响。
- 已安装版本会根据实例 JSON / `pmgl_pack.json` 自动识别加载器，
  显示 `forge.png`、`fabric.png`、`neo_forge.png`、`optifine.png` 对应图标；原版和快照仍使用两张基础图标。
- 下载列表不再显示 `[已安装]` 后缀。
- 同一 MC 版本可以重复安装，但实例名称必须唯一；已安装时默认名称会自动追加 `(2)`、`(3)`。
- 文件补全会并行下载（线程数跟随全局设置），官方源过慢时会自动切换镜像源。
- 取消安装后留下的未完成目录会显示为隐藏状态，不会出现在已安装版本列表中。

### 版本校验与下载管理
- 「已安装版本」会自动校验版本 JSON、客户端 JAR、依赖库和资源索引；
  可修复的缺陷标红为 `[需修复]`，严重错误标红为 `[错误：不可启动]`，后者不能选择或启动。
- 启动游戏前会快速校验并自动补全缺失文件，修复完成后再启动。
- 所有页面底部会显示下载/修复进度条；点击进度条打开「下载管理」页面，
  可查看总进度、剩余步骤以及各任务每个阶段的百分比。
- 启动器主窗口固定为 16:9，使用自定义无边框圆角标题栏（最小化 / 关闭）。
- 全局设置 → 启动选项：默认版本隔离、游戏窗口标题、启动器可见性、进程优先级、游戏窗口大小。
- 每个下载任务右上角都有 ×：进行中点击会取消下载，失败任务可点击关闭。
- 成功或主动取消的任务会自动从下载管理中移除；失败任务会保留并标红，方便查看错误原因。
- 启动新游戏时会清空首页日志显示并只显示新实例的日志，旧实例日志仍保存在 `log/` 文件中。
- 已安装版本中完整的版本正常显示；损坏版本只能查看和删除，不能作为启动版本。

### GUI 背景深度
全局设置 → 背景图片 新增「GUI 背景深度」滑条，数值越高界面整体颜色越深，背景图仍会保留。

### 标题与字体
- 全局设置 → 启动器标题可自定义标题文字和颜色，颜色支持 `#RRGGBB` / `#AARRGGBB`，默认 `#4a9eff`。
- 启动器会自动加载 `font/` 目录中的字体（当前使用 HarmonyOS Sans SC）并应用到整体 UI；
  文件夹为空时回退到系统 Segoe UI。
- 标题和标题颜色在输入时实时生效，无需点击应用按钮。
- 下载完成或本地导入的整合包都会强制启用版本隔离，游戏目录位于 `versions/<整合包名>/`。
- 整合包导入使用内置页面，不再弹出二级窗口。

### 窗口与弹窗
- 启动器窗口固定为 16:9，使用自定义圆角无边框窗口和标题栏（最小化 / 关闭）。
- 启动失败、错误、警告提示使用深色圆角弹窗，仅保留右上角关闭 ×。
- 退出确认等 Yes/No 确认框同样使用居中深色圆角弹窗。
- 所有页面的返回箭头统一为同一个圆角箭头按钮。

### JDK 版本建议
全局设置 → Java 列表 中提供 JDK 对照表：
- 1.0 ~ 1.16.5：JDK 8 / Temurin 8
- 1.17：最低 JDK 16，推荐 JDK 17
- 1.18 ~ 1.20.4：JDK 17 / Temurin 17
- 1.20.5 ~ 1.21.11：JDK 21 / Temurin 21
- 26.1+：JDK 25 / Temurin 25

游戏设置页也会显示当前版本的 JDK 最低/推荐版本。

### Mod 管理
- 安装了 Fabric / Forge / NeoForge / Quilt / OptiFine 的版本，首页「启动游戏」右侧会出现「管理模组」。
- Mod 管理是「启动」页面内的子页面，不再是独立窗口，左上角箭头可返回。
- 支持搜索、全选、多选，以及更新 / 启用 / 禁用 / 删除 / 取消选择；禁用的文件会改名为 `.jar.disabled`。
  列表上方可切换「全部 / 可更新」。

### 版本管理与启动脚本
- 版本隔离现在直接使用 `versions/<版本名>/` 作为游戏目录，Mod 位于 `versions/<版本名>/mods`；
  旧版 `<版本名>/game` 中的数据会在启动时自动迁移。
- 「游戏设置 → 版本管理」可快速打开版本 / 存档 / Mod 文件夹。
- 「游戏设置 → 游戏修复」右侧的「导出启动脚本」可选择目录并生成 `导出<版本名>.bat`
  （GBK 编码，双击即可启动当前版本）。

### 日志
所有启动器日志、Forge / NeoForge / OptiFine 安装器日志和游戏输出日志统一保存在项目根目录的
`log/` 文件夹。全局设置 → 日志 中可打开该文件夹或一键清空全部日志。

## ⚠️ 注意事项

### 路径问题
- **游戏目录请勿包含中文**，否则会导致游戏崩溃或资源加载失败
- 建议使用默认路径 `~/.minecraft`

### Java 选择
- Windows 请选择 `javaw.exe`（无控制台窗口），不要选 `java.exe`
- Java 版本必须与 Minecraft 版本匹配

### 内存设置
- 建议最大内存不超过系统总内存的 50%
- 原版游戏 2G~4G 足够，Mod 整合包可适当增加到 6G~8G

## 🔧 技术栈

| 模块 | 技术 |
|---|---|
| UI 框架 | PySide6 (Qt for Python) |
| UI 组件库 | PyQt-Fluent-Widgets (Fluent Design) |
| 启动核心 | minecraft-launcher-lib |
| 动画 | QPropertyAnimation + QPainter 自绘 |
| 多线程 | QThread + Signal/Slot |
| 配置持久化 | JSON 原子写入 |

## 📝 开发说明

### 线程安全
所有后台操作（下载、启动、登录）均在 QThread 中执行，通过 Signal/Slot 与 UI 通信，**绝对不在子线程中直接操作 GUI 控件**。

### 异常处理
- 网络异常、权限错误、版本不存在等均有明确捕获和提示
- 配置文件采用原子写入（先写临时文件再替换），避免中途崩溃损坏

### 扩展方向
- Mod / 整合包管理
- 皮肤预览与更换
- 多实例隔离
- Forge / Fabric / Quilt 自动安装
- 游戏截图管理
